Capability Firewall & Blast-Radius Simulator

Evaluate AI agent shell, git, SQL, and network commands before execution. Simulate filesystem blast radius offline and record every decision in a tamper-evident SHA-256 hash-chained audit ledger.

agentfence check "git push --force origin main" --json
agentfence run --ledger .agentfence/audit.jsonl -- pytest -q
agentfence verify-ledger .agentfence/audit.jsonl
